About

About DKSPORTS

A clean, fast, responsive football catalog that pulls live data from football-data.org and live odds from The Odds API, and presents it all in one beautiful place.

Tech stack

  • · Python 3 · Flask
  • · Bootstrap 5 · Bootstrap Icons
  • · Vanilla JavaScript
  • · football-data.org REST API
  • · The Odds API (live betting odds)

What you get

  • · Live league standings & form
  • · Top scorers, assists & cards leaderboards
  • · Full team rosters & staff
  • · Upcoming fixtures with 1·X·2 odds
  • · Match details and scores
  • · Player profile pages

About the data

Match data is fetched from football-data.org. The free tier includes top European leagues, the Brazilian Série A, World Cup, European Championship and the Champions League. Other competitions may show "tier-locked" labels.

Live betting odds are provided by The Odds API (h2h decimal odds, EU bookmakers). Odds are best-available across covered bookmakers.
